### 8. [co-016] coding · 模型 glm-5.3-flash · 自动裁判分 4.9

**题目：**

> 用 Python 写函数 rotate_list(nums, k)，把数组向右轮转 k 步，返回新列表。k 可能大于数组长度。函数名必须是 rotate_list。

**模型回答：**

下面是简洁的实现：

```python
def rotate_list(nums, k):
    """
    将列表向右轮转 k 步，返回新列表（不修改原列表）。

    例如: rotate_list([1, 2, 3, 4, 5], 2) -> [4, 5, 1, 2, 3]
    """
    n = len(nums)
    if n == 0:          # 空列表直接返回，避免取模报错
        return []
    k %= n              # 处理 k 大于数组长度的情况
    return nums[-k:] + nums[:-k]
```

**要点说明**

- `k %= n`：向右轮转 `n` 步等于没转，所以只需轮转 `k % n` 步，这样 `k` 再大也没问题。
- `nums[-k:]` 是最后 `k` 个元素（会转到开头），`nums[:-k]` 是前面剩余部分（会转到后面），拼接即得结果。
- 当 `k % n == 0` 时，`nums[-0:]` 是整个列表、`nums[:-0]` 是空列表，拼接结果正好是原列表，无需特殊处理。

**测试示例**

```python
print(rotate_list([1, 2, 3, 4, 5], 2))   # [4, 5, 1, 2, 3]
print(rotate_list([1, 2, 3, 4, 5], 7))   # [4, 5, 1, 2, 3]  (7 % 5 == 2)
print(rotate_list([1, 2], 5))            # [2, 1]           (5 % 2 == 1)
print(rotate_list([1, 2, 3], 0))         # [1, 2, 3]
print(rotate_list([], 3))                # []
```

### 9. [co-021] coding · 模型 glm-5.3-flash · 自动裁判分 5.0

**题目：**

> 用 Python 写函数 majority_element(nums)，返回出现次数严格超过数组长度一半的元素。假设一定存在这样的元素。要求空间复杂度 O(1)，也就是不能用哈希计数。函数名必须是 majority_element。

**模型回答：**

使用 **Boyer–Moore 投票算法**，时间 O(n)，空间 O(1)：

```python
def majority_element(nums):
    candidate = None
    count = 0
    for num in nums:
        if count == 0:
            candidate = num
        count += 1 if num == candidate else -1
    return candidate
````

## 原理

把问题想象成"投票抵消"：

- `candidate` 是当前的候选众数，`count` 是它的"票数净值"。
- 遇到相同元素，票数 +1；遇到不同元素，相当于抵消一票。
- 票数归零时，说明当前候选已和其他元素完全抵消，换下一个元素作为新候选。

**为什么正确**：多数元素出现次数超过 n/2，即使它和所有其他元素一一抵消，剩下的也一定还是它。因为题目保证多数元素一定存在，所以最后剩下的 `candidate` 就是答案，无需二次验证。

## 示例

```python
print(majority_element([3, 2, 3]))            # 3
print(majority_element([2, 2, 1, 1, 1, 2, 2]))  # 2
print(majority_element([7]))                   # 7
```

以 `[2, 2, 1, 1, 1, 2, 2]` 为例：

| num | candidate | count |
| --- | --------- | ----- |
| 2   | 2         | 1     |
| 2   | 2         | 2     |
| 1   | 2         | 1     |
| 1   | 2         | 0     |
| 1   | 1         | 1     |
| 2   | 1         | 0     |
| 2   | 2         | 1     |

最终返回 `2`。
